# BinTrack for Android

This folder is BinTrack packaged as an installable app (a PWA). It works offline once installed. Your data is saved on the phone it is installed on.

## Option A: install it from Chrome (easiest)
1. Put this whole folder on any web host that uses https (GitHub Pages, Netlify, Cloudflare Pages, or your own site). Keep the files together.
2. On your Android phone, open the site in Chrome.
3. Tap the three dots, then **Install app** (or **Add to Home screen**).
4. BinTrack appears on your home screen and opens full screen, without the browser bar.

## Option B: a real APK / Play Store app
1. Host the folder as in Option A.
2. Go to pwabuilder.com, enter your site's address, and choose **Android**.
3. Download the package. It contains an APK you can install directly and an AAB for the Play Store.

## Notes
- Back up often: Settings, then Download backup. Backups are the only way to move data between phones.
- Files are saved to the phone's Downloads folder.
- Edit icons in the icons folder if you want a different logo.
